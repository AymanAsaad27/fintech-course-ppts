# 汇报文件 | Presentation Files

这里存放大家的金科课汇报 PPT，以及可选的同名 PDF。<br>
This directory contains FinTech course presentation slides and optional PDFs with matching filename stems.

文件命名为 `汇报主题_姓名或组号.pptx`，例如 `数字人民币_第1组.pptx`。<br>
Name your file `Topic_Name-or-Group.pptx`, for example `Digital-RMB_Group1.pptx`. Chinese filenames are also welcome.
