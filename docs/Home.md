# 金科课课程 Wiki

欢迎使用金科课汇报资料库。这里整理课程汇报资料的入口、上传方式与维护说明。

## 常用入口

- [汇报索引](https://github.com/yequanzhen02-maker/fintech-course-ppts#汇报索引)：按主题、汇报人或小组查找资料。
- [全部 PPT 与 PDF](https://github.com/yequanzhen02-maker/fintech-course-ppts/tree/main/presentations)：浏览或下载已收录的文件。
- [上传指南](https://github.com/yequanzhen02-maker/fintech-course-ppts/blob/main/CONTRIBUTING.md)：使用浏览器提交自己的汇报。
- [问题与反馈](https://github.com/yequanzhen02-maker/fintech-course-ppts/issues)：反馈资料错误、失效链接或上传问题。
- [维护说明](https://github.com/yequanzhen02-maker/fintech-course-ppts/blob/main/docs/维护说明.md)：供仓库维护者收录和更新资料时参考。

## 资料如何收录

同学提交 PPT → 发起 Pull Request → 维护者合并 → 更新首页索引。

PPT 与 PDF 统一存放在主仓库的 `presentations/` 目录；Wiki 提供说明与导航。

## 如何阅读

浏览资料无需登录。下载 PPT 后用 PowerPoint、WPS 或 Keynote 打开；有 PDF 的汇报可以直接在线预览。

资料版权归原作者所有。引用时请注明作者与来源，其他使用方式以作者授权为准。
