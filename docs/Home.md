# 金科课课程 Wiki | FinTech Course Wiki

欢迎使用金科课汇报资料库。这里整理课程汇报资料的入口、上传方式与维护说明。<br>
Welcome to the FinTech course presentation repository. This wiki provides links to slides, upload instructions, and maintainer guidance.

## 常用入口 / Quick links

- [汇报索引 / Presentation index](https://github.com/soxee1/fintech-course-ppts#presentation-index)：按主题、汇报人或小组查找资料。Browse by topic, presenter, or group.
- [全部 PPT 与 PDF / All slides and PDFs](https://github.com/soxee1/fintech-course-ppts/tree/main/presentations)：浏览或下载已收录文件。Browse or download contributed files.
- [上传指南 / Upload guide](https://github.com/soxee1/fintech-course-ppts/blob/main/CONTRIBUTING.md)：使用浏览器提交汇报。Submit your presentation through a browser.
- [问题与反馈 / Questions and feedback](https://github.com/soxee1/fintech-course-ppts/issues)：反馈资料错误、失效链接或上传问题。Report errors, broken links, or upload problems.
- [维护说明 / Maintainer guide](./维护说明.md)：收录和更新资料的方法。Instructions for collecting and updating materials.

## 资料如何收录 / How submissions are collected

同学提交 PPT → 发起 Pull Request → 维护者合并 → 更新首页索引。<br>
Upload slides → Open a pull request → Maintainer merges it → Update the homepage index.

PPT 与 PDF 统一存放在主仓库的 `presentations/` 目录，Wiki 提供说明与导航。<br>
Slides and PDFs are stored in the main repository's `presentations/` directory. The wiki provides guidance and navigation.

## 如何阅读 / Reading and downloading

浏览资料无需登录。下载 PPT 后用 PowerPoint、WPS 或 Keynote 打开；PDF 可以直接在线预览。<br>
No sign-in is needed to browse. Download slides and open them in PowerPoint, WPS, or Keynote. PDFs can be previewed online.
