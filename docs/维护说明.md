# 维护说明 | Maintainer Guide

## 收录汇报 / Add a presentation

1. 在 **Pull requests** 中查看同学提交的文件和汇报信息。<br>
   Open **Pull requests** to review the submitted files and presentation details.
2. 检查文件可下载、命名清楚且适合公开分享，然后合并。<br>
   Check that the files can be downloaded, are clearly named, and are suitable for public sharing, then merge the submission.
3. 更新首页 `README.md` 的汇报索引，填入日期、主题、姓名或组号和文件链接；没有 PDF 时填 `—`。<br>
   Update the presentation index in `README.md` with the date, topic, presenter or group, and file links. Use `—` when no PDF is available.
4. 收录第一份资料后，删除首页索引的占位行，以及 `presentations/README.md` 中尚无资料的中英文提示。<br>
   After adding the first presentation, remove the placeholder index row and both empty-directory notices in `presentations/README.md`.

## 常用操作 / Common tasks

- **更正资料 / Update files**：替换同名文件后提交，不要不断增加“最终版”文件。Replace the existing file and commit the change instead of adding multiple files named “final”.
- **邀请协作者 / Invite collaborators**：在 **Settings → Collaborators** 中邀请对应用户。普通同学通过 Fork 和 Pull Request 提交即可。Invite users through **Settings → Collaborators**. Other students can contribute through forks and pull requests without an invitation.
- **处理大文件 / Handle large files**：优先压缩图片或去除嵌入视频。使用外部链接时，请在索引中记录链接与有效期。Compress images or remove embedded videos first. If an external download link is necessary, include the link and its expiration date in the index.
- **维护 Wiki / Maintain the wiki**：课程 Wiki 文档位于 `docs/Home.md`。如同时使用独立的 GitHub Wiki 页面，请同步相关说明。The course wiki document is `docs/Home.md`. If separate GitHub Wiki pages are also used, keep their guidance in sync.
