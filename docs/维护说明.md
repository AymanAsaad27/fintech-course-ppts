# 维护说明

## 收录汇报

1. 在 **Pull requests** 中查看同学提交的文件和汇报信息。
2. 检查文件可下载、命名清楚且适合公开分享，然后合并。
3. 更新 `README.md` 与 `README.zh-CN.md` 中的汇报索引，填入日期、主题、姓名或组号和文件链接；没有 PDF 时填 `—`。
4. 收录第一份资料后，删除两份首页索引的占位行，以及 `presentations/README.md` 和 `presentations/README.zh-CN.md` 中尚无资料的提示。

## 常用操作

- **更正资料**：替换同名文件后提交，不要不断增加“最终版”文件。
- **邀请协作者**：在 **Settings → Collaborators** 中邀请对应用户。普通同学通过 Fork 和 Pull Request 提交即可。
- **处理大文件**：优先压缩图片或去除嵌入视频。使用外部下载链接时，请在中英文索引中记录链接与有效期。
- **维护语言版本**：默认显示英文。修改导航或说明时，请同步对应的中文版，并保留页面顶部的语言切换链接。
