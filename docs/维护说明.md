# 维护说明

## 收录一份汇报

1. 在 **Pull requests** 中查看同学提交的文件和汇报信息。
2. 检查文件可下载、命名清楚且适合公开分享，然后合并。
3. 更新首页 `README.md` 中的汇报索引，填入日期、主题、姓名或组号和文件链接；没有 PDF 时填 `—`。
4. 收录第一份资料后，删除首页索引中的占位行，以及 `presentations/README.md` 中“目前还没有收录汇报资料”的提示。

## 常用操作

- **更正资料**：上传同名文件进行替换，再提交更改。不要不断增加“最终版”“最终最终版”文件。
- **邀请固定协作者**：在仓库 **Settings → Collaborators** 中邀请对应 GitHub 用户。普通同学使用 Fork 和 Pull Request 即可提交，不需要逐一邀请。
- **处理大文件**：优先压缩图片或去除嵌入视频。若必须用外部下载链接，请将链接和有效期记入汇报索引。
- **维护 Wiki**：课程 Wiki 的源文档位于 `docs/Home.md`。修改主仓库文档后，如同时使用 GitHub Wiki 页面，请同步相应说明。
