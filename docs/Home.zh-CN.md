# 金科课课程 Wiki

欢迎使用金科课汇报资料库。这里整理课程汇报资料的入口、上传方式与维护说明。

## 常用入口

- [汇报索引](../README.zh-CN.md#presentation-index)：按主题、汇报人或小组查找资料。
- [汇报文件](../presentations/README.zh-CN.md)：查看资料说明并进入文件目录。
- [上传指南](../CONTRIBUTING.zh-CN.md)：使用浏览器提交汇报。
- [问题与反馈](https://github.com/soxee1/fintech-course-ppts/issues)：反馈资料错误、失效链接或上传问题。
- [维护说明](./维护说明.md)：收录和更新资料的方法。

## 资料如何收录

同学提交 PPT → 发起 Pull Request → 维护者合并 → 更新中英文首页索引。

PPT 与 PDF 统一存放在主仓库的 `presentations/` 目录，Wiki 提供说明与导航。

## 如何阅读

浏览资料无需登录。下载 PPT 后用 PowerPoint、WPS 或 Keynote 打开；PDF 可以直接在线预览。

资料版权归原作者所有。引用请注明作者与来源，其他使用方式以作者授权为准。
