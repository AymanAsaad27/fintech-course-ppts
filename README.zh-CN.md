## 如何提交

1. 文件命名为 `汇报主题_姓名或组号.pptx`，例如 `数字人民币_第1组.pptx`。
2. 点击右上角 **Fork**，在自己的副本中进入 `presentations`，选择 **Add file → Upload files**，上传 PPT 和可选的同名 PDF。
3. 保存后点击 **Contribute → Open pull request**，在说明中填写汇报日期、主题和姓名或组号。
4. 维护者合并后，资料即可被大家查看和下载，并补充到上方索引。

第一次使用 GitHub，可以按[详细上传指南](./CONTRIBUTING.zh-CN.md)操作。已有写入权限的协作者可以直接上传。

## 文件与使用说明

- 接收 `.pptx`、`.ppt`；欢迎同时提供 `.pdf`，便于在线预览。更新汇报时请替换同名文件。
- 网页上传单个文件上限为 **25 MiB**。大文件请先压缩图片、移除嵌入视频，或在提交说明中提供下载链接，由维护者协调收录。
- 请仅提交适合公开分享的课程资料。版权归原作者所有，引用请注明作者与来源，其他使用方式以作者授权为准。
